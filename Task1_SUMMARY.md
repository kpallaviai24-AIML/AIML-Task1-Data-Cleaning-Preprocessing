# Project Summary

## Task Name

Data Cleaning and Preprocessing

## Dataset

Titanic Dataset

## Objective

To clean and preprocess raw data so that it becomes suitable for machine learning applications.

## Work Performed

1. Explored the dataset structure and data types.
2. Identified missing values in Age, Cabin, and Embarked columns.
3. Filled missing Age values using Median.
4. Filled missing Embarked values using Mode.
5. Removed Cabin column due to excessive missing values.
6. Encoded categorical columns using Label Encoding.
7. Standardized numerical features using StandardScaler.
8. Detected outliers using Boxplots.
9. Removed outliers using the IQR method.
10. Generated a cleaned dataset and saved it as CSV.

## Result

The dataset was successfully cleaned, transformed, and prepared for machine learning model development.
